==================================================
OBJETIVO
==================================================

O diretório External References do PromptCoreLabs_AEOS gerencia e cataloga as referências a repositórios, documentações e recursos externos que são integrados ou consumidos pela plataforma.

Isso evita a poluição do repositório local com clones aninhados de repositórios externos.
