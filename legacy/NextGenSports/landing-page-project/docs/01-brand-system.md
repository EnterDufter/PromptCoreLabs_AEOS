# Brand System

## Direção visual

Estética de "engineering dossier premium": relatório executivo, blueprint técnico, infográfico institucional e plataforma SportTech. O visual deve parecer sóbrio, confiável e estratégico, com densidade informacional controlada.

## Paleta conceitual

- Off-white técnico: base clara para leitura e sofisticação.
- Cinza técnico: apoio para grids, áreas neutras e separações.
- Azul petróleo: cor institucional principal.
- Grafite: texto principal e áreas de alto contraste.
- Ciano moderado: acentos, estados e detalhes técnicos.

## Tipografia

Usar tipografia moderna, limpa e legível. A fonte base do projeto é Inter via `next/font`. Headlines devem ser fortes, mas sem exagero promocional.

## Componentes visuais

- Grid sutil de fundo.
- Cartões técnicos com bordas finas.
- Etiquetas em estilo monoespaçado para códigos, etapas e módulos.
- Linhas e divisórias discretas.
- Blocos informacionais com alta legibilidade.

## Linguagem de imagens

Quando imagens forem adicionadas, devem priorizar contexto real de esporte, engenharia, pista, capacete, telemetria, treinamento, bastidores e desenvolvimento. Evitar imagens genéricas de startup ou fotos excessivamente dramáticas.

## O que evitar

- Neon excessivo.
- Visual gamer ou e-sports.
- Gradientes chamativos.
- Mockups genéricos demais.
- Depoimentos fictícios.
- Logos de marcas sem autorização.
