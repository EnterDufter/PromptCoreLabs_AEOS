# Arquitetura de Conteúdo

## Estrutura da landing page

1. Hero
2. Problema
3. Solução
4. Pilares da plataforma
5. Como funciona
6. Caso inicial: Motorsport
7. Valor para parceiros
8. CTA final

## Objetivo de cada seção

- Hero: apresentar a tese institucional da plataforma e abrir dois caminhos de ação.
- Problema: mostrar a fragmentação enfrentada por talentos emergentes.
- Solução: posicionar a NextGen Sports como estrutura de carreira, dados, mídia e parcerias.
- Pilares: organizar as capacidades principais da plataforma.
- Como funciona: traduzir o método em fluxo simples.
- Caso inicial: explicar o motorsport como primeiro território sem inventar cases.
- Valor para parceiros: mostrar por que marcas podem se associar ao projeto.
- CTA final: convidar para apresentação ou conversa de parceria.

## Mensagens principais

- Potencial esportivo precisa de estrutura profissional.
- Parceria é mais forte que apoio pontual.
- Dados, narrativa e governança aumentam valor institucional.
- Motorsport valida o método inicial, com expansão futura possível.
