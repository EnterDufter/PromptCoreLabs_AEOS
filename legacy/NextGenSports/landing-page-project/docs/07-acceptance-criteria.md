# Critérios de Aceite

## Visual

- Fundo claro técnico com grid sutil.
- Paleta sóbria com azul petróleo, grafite e ciano moderado.
- Aparência de blueprint executivo.
- Cards com bordas finas e boa hierarquia visual.
- Ausência de estética gamer, neon excessivo ou visual infantil.

## Técnico

- `npm run build` executa sem erros.
- `npm run lint` executa sem erros bloqueantes.
- App Router em `src/app`.
- TypeScript e Tailwind configurados.
- Componentes e seções organizados conforme estrutura definida.

## Conteúdo

- Não há métricas inventadas.
- Não há patrocinadores fictícios.
- Não há depoimentos fictícios.
- A proposta é de plataforma e parceria, não pedido amador de patrocínio.

## Responsividade

- Hero legível em mobile e desktop.
- Cards reorganizados sem quebrar layout.
- CTAs acessíveis em telas pequenas.
- Nenhum texto sobreposto.
