# Prompt: Build Homepage

Use este prompt para evoluir a homepage da NextGen Sports.

## Contexto

A NextGen Sports é uma plataforma SportTech institucional para desenvolvimento de talentos esportivos emergentes, começando por automobilismo/kartismo.

## Objetivo

Construir ou melhorar a homepage mantendo a estética "engineering dossier premium": fundo claro técnico, grid sutil, azul petróleo, grafite, ciano moderado, cartões técnicos e aparência de blueprint executivo.

## Regras

- Não inventar métricas, patrocinadores, pilotos, resultados ou depoimentos.
- Não transformar a página em pedido amador de patrocínio.
- Usar `src/data/landingContent.ts` para conteúdo recorrente.
- Manter seções em `src/sections`.
- Manter componentes reutilizáveis em `src/components`.
- Garantir responsividade e boa leitura mobile.

## Seções obrigatórias

- Hero
- Problema
- Solução
- Pilares
- Como funciona
- Caso Motorsport
- Valor para parceiros
- CTA final
