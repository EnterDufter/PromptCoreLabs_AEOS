# Prompt: QA Checklist

Revise a landing page NextGen Sports antes de entrega.

## Visual

- Fundo claro técnico com grid sutil.
- Bordas finas e estética blueprint.
- Sem neon excessivo, gamer ou e-sports.
- Textos legíveis em mobile e desktop.

## Conteúdo

- Não existem métricas inventadas.
- Não existem patrocinadores fictícios.
- Não existem depoimentos fictícios.
- A proposta comunica plataforma e parceria.

## Técnico

- `npm run build` passa.
- `npm run lint` passa.
- App Router em `src/app`.
- Componentes e seções organizados.

## Acessibilidade

- Um único `h1`.
- Hierarquia de headings coerente.
- CTAs com texto claro.
- Contraste aceitável.
