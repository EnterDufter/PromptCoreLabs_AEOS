==================================================
OBJETIVO
==================================================

Prover os templates em branco da metodologia TLC Spec-Driven v3 para uso em qualquer projeto ou recurso gerenciado pelo PromptCoreLabs_AEOS.

==================================================
TEMPLATES DISPONÍVEIS
==================================================

• specify-template.md
  Template para a etapa SPECIFY. Cobre escopo, requisitos funcionais, não funcionais e critérios de segurança.

• design-template.md
  Template para a etapa DESIGN. Cobre arquitetura de software, componentes, fluxo de dados e matriz de rastreabilidade.

• tasks-template.md
  Template para a etapa TASKS. Cobre backlog estruturado de tarefas atômicas mapeadas para requisitos.

• validate-template.md
  Template para a etapa VALIDATE. Cobre resultados de testes, critérios de aceite verificados e conformidade com especificações.

==================================================
COMO USAR
==================================================

1. Copie o arquivo desejado para a pasta do seu projeto:
   .specs/projects/[nome-do-projeto]/

2. Renomeie para o nome de artefato correspondente (ex: specify.md).

3. Preencha os campos entre colchetes [ ] conforme o contexto do projeto.

4. Solicite aprovação do gate antes de avançar para a próxima etapa TLC.
