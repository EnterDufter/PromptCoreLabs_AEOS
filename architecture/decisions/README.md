==================================================
OBJETIVO
==================================================

Este diretório contém os Architecture Decision Records (ADRs) oficiais do PromptCoreLabs_AEOS.

Cada ADR registra uma decisão arquitetural permanente que alterou estrutura, módulos, princípios ou responsabilidades da plataforma.

==================================================
CONVENÇÃO DE NOMENCLATURA
==================================================

ADR-[NÚMERO-4-DÍGITOS]-[titulo-em-kebab-case].md

Os IDs nunca são reutilizados ou excluídos.

==================================================
ESTADOS POSSÍVEIS

• Proposed  — aguardando aprovação do arquiteto
• Accepted  — aprovado e em vigor
• Superseded — substituído por ADR mais recente
• Deprecated — obsoleto mas mantido como histórico
• Rejected   — avaliado e recusado
