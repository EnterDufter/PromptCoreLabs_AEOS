# TLC Spec-Driven v3

Fonte da metodologia TLC Spec-Driven v3 no workspace `C:\PromptCore_Labs`.

## Artefatos

- `specify.md`: escopo e requisitos da metodologia.
- `design.md`: arquitetura detalhada da metodologia.
- `tasks.md`: backlog tecnico da metodologia.
- `execute.md`: registro da instalacao metodologica.
- `validate.md`: criterios de validacao e auditoria.
- `rag.md`: registro de decisoes, premissas e integracoes futuras.

## Fluxo

```text
SPECIFY -> DESIGN -> TASKS -> EXECUTE -> VALIDATE
```

## Regra central

Toda iniciativa futura deve usar os templates adequados e registrar aprovacoes entre etapas.
