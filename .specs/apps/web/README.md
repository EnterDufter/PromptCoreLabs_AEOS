# Apps Web

Specs de aplicacoes web devem ficar em subpastas com slug explicito.

Exemplos atuais:

- `C:\PromptCore_Labs\.specs\apps\web\promptcore-labs-website\specify.md`
- `C:\PromptCore_Labs\.specs\apps\web\nextgen-sports\specify.md`

Evitar arquivos genericos como `C:\PromptCore_Labs\.specs\apps\web\specify.md`, pois eles misturam escopos de apps diferentes.
