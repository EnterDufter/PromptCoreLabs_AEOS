# Landing Page Review Skill

Use esta skill para revisar a landing page da NextGen Sports.

## Quando usar

- Antes de entregar uma nova versão da homepage.
- Após mudanças de copy, layout ou componentes.
- Antes de preparar deploy.

## Checklist de alinhamento

1. Confirmar que a página comunica plataforma SportTech institucional.
2. Confirmar que a narrativa é de parceria, performance, dados, mídia e governança.
3. Verificar se não há métricas, patrocinadores, depoimentos, pilotos ou resultados fictícios.
4. Verificar se a estética segue "engineering dossier premium".
5. Confirmar que o visual não parece gamer, e-sports, infantil ou startup genérica.
6. Validar responsividade básica.
7. Rodar `npm run build` e `npm run lint` quando possível.

## Saída esperada

Relatar problemas por prioridade:
- Bloqueadores técnicos.
- Riscos de comunicação.
- Ajustes visuais.
- Melhorias de conteúdo.

Se não houver problemas críticos, informar que a base está adequada e listar riscos residuais.
