# Prompt: Refactor Components

Refatore componentes da landing page NextGen Sports sem alterar o posicionamento estratégico.

## Objetivo

Melhorar legibilidade, reutilização e consistência visual.

## Regras

- Preservar a estrutura `src/components`, `src/sections`, `src/data`.
- Evitar abstrações desnecessárias.
- Não quebrar conteúdo ou responsividade.
- Manter Tailwind CSS como sistema de estilo.
- Não adicionar bibliotecas sem necessidade clara.

## Validação

Após refatorar, rodar:

```bash
npm run build
npm run lint
```
