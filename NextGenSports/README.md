# NextGen Sports (NGS) Platform

Plataforma de aceleração para jovens pilotos de kart, integrando telemetria real e gamificação via Digital Twin.

## 📁 Estrutura do Repositório

- `skill_tree.json`: Estrutura lógica das competências e badges do piloto.
- `telemetry_simulator.py`: Simulador de validação de performance via Digital Twin.

## ⚙️ Como Executar o Simulador

```powershell
python telemetry_simulator.py
```
