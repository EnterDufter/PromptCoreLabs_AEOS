# Princípios Fundacionais

1. O conhecimento pertence ao AEOS.
2. Todo LLM é substituível.
3. Toda inteligência permanente é documentada.
4. Nenhum agente aprova seu próprio trabalho.
5. Todo projeto nasce da especificação.
6. Todo artefato possui um responsável.
7. Todo conhecimento é versionado.
8. Agentes recebem apenas contexto mínimo.
9. Decisões importantes entram no RAG.
10. O AEOS é independente de fornecedor.
